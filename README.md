# Прогнозирование продаж новых коммерческих автомобилей марки ГАЗ и спроса на них с применением классических ML-моделей и архитектуры Transformer

В данной работе мы решаем задачу прогнозирования двух целевых переменных (target):

- quantity — объём продаж новых коммерческих автомобилей ГАЗ;
- applications — объём спроса, выраженный количеством заявок.

Сравниваются сезонный наивный прогноз, **SARIMA, Random Forest, XGBoost и Transformer**.

Методология адаптирована к небольшому помесячному ряду: последние 12 месяцев — test, предыдущие 12 — validation, более ранние данные — train. Данные не перемешиваются.

> Для ML-моделей и Transformer тестовый период прогнозируется рекурсивно. Фактические значения целевой переменной из будущих тестовых месяцев не используются при создании лагов следующего месяца.

> В ретроспективном тесте за 2025 год внешние макроэкономические показатели считаются известными. Поэтому результаты моделей с внешними факторами следует интерпретировать как **условный прогноз при известных внешних условиях**. Для реального прогноза будущих месяцев потребуются прогнозные или сценарные значения макроэкономических факторов.

# Цель и постановка задачи

Цель проекта — разработать и сравнить несколько подходов к прогнозированию продаж новых коммерческих автомобилей марки ГАЗ и спроса на них.

В рамках проекта решаются следующие задачи:
1. загрузка и объединение исходных данных;
2. очистка и подготовка временного ряда;
3. исследование трендов, сезонности и структурных изменений;
4. создание лаговых признаков и скользящих статистик;
5. добавление внешних экономических факторов;
6. построение обучающей, проверочной и тестовой выборок без перемешивания наблюдений;
7. обучение нескольких прогнозных моделей;
8. подбор параметров моделей на проверочном периоде;
9. формирование рекурсивного прогноза на 12 месяцев;
10. оценка качества прогнозов по нескольким метрикам;
11. сравнение моделей с сезонным наивным прогнозом;
12. анализ важности признаков и поведения моделей при резких изменениях ряда;
13. формирование интерактивного дашборда и файлов с результатами.

applications — количество заявок за месяц.

# Методология
## 1. Предобработка данных

В рамках подготовки данных выполняются:
- преобразование даты;
- объединение таблиц по году и месяцу;
- обработка пропусков;
- проверка необычных значений;
- сохранение реальных экстремальных значений макроэкономических факторов;
- проверка временной последовательности;
- формирование целевых переменных.

Для макроэкономических показателей межквартильный размах используется только как диагностический инструмент. Значения не обрезаются, поскольку высокий уровень ключевой ставки или других показателей может отражать реальный новый режим рынка, а не ошибку в данных.

## 2. Разведочный анализ

Исследуются:
- динамика продаж;
- динамика заявок;
- тренд;
- годовая сезонность;
- остаточная компонента;
- корреляции с внешними факторами;
- возможные структурные изменения временных рядов.

Для исследования тренда и сезонности используется STL-разложение.

## 3. Создание признаков

Для моделей машинного обучения создаются:
- лаги за 1, 2, 3, 6 и 12 месяцев;
- скользящие средние;
- скользящие стандартные отклонения;
- годовые изменения;
- календарные признаки;
- циклические признаки месяца;
- внешний экономический контекст.

Лаговые и скользящие признаки рассчитываются только на основе прошлых значений. Значение целевой переменной прогнозируемого месяца не используется в качестве входного признака.

## 4. Разбиение данных

Временной ряд не перемешивается.
Используется хронологическое разделение:
- обучающая выборка — более ранняя история;
- проверочная выборка — 12 месяцев перед тестовым периодом;
- тестовая выборка — последние 12 месяцев, то есть 2025 год.

Проверочная выборка используется для выбора параметров моделей.
Тестовая выборка используется только для итогового сравнения.

## 5. Рекурсивный прогноз

Для моделей машинного обучения и Transformer прогноз на 12 месяцев формируется рекурсивно.
Сначала прогнозируется первый месяц. Полученное значение используется при расчёте лаговых признаков следующего месяца. Процедура повторяется до конца прогнозного горизонта.

Такой подход предотвращает использование фактических значений будущих месяцев при формировании лагов.

# Используемые модели

В проекте сравниваются пять подходов.

## 1. Сезонный наивный прогноз

Базовый прогноз:

> значение прогнозируемого месяца принимается равным значению того же месяца предыдущего года.

Используется как минимальный ориентир качества.

## 2. SARIMA

Статистическая модель временных рядов, учитывающая:
- авторегрессию;
- разности;
- скользящее среднее;
- годовую сезонность.

Параметры выбираются по минимальному RMSE на проверочной выборке.
После выбора параметров модель переобучается на объединённых обучающей и проверочной выборках и прогнозирует тестовый период.

## 3. Random Forest

Ансамблевая модель на основе множества деревьев решений.
В качестве признаков используются:
- лаговые значения;
- скользящие статистики;
- календарные признаки;
- внешние факторы.

## 4. XGBoost

Модель градиентного бустинга по деревьям решений.

Использует тот же набор временных и внешних признаков и позволяет моделировать нелинейные зависимости.

## 5. TransformerEncoder

Небольшая нейронная архитектура на основе TransformerEncoder.

На вход подаются:
- 12 предыдущих месяцев;
- исторические значения целевой переменной;
- внешние факторы;
- календарные признаки;
- известные или сценарные внешние показатели прогнозируемого месяца.

Размер модели ограничен, поскольку в распоряжении имеется только 84 месячных наблюдения.

# Метрики качества

Для сравнения моделей используются четыре метрики регрессии:

## MAE — средняя абсолютная ошибка
Показывает среднее абсолютное отклонение прогноза от фактического значения.

## RMSE — корень из средней квадратичной ошибки
Сильнее штрафует большие ошибки и используется как основной показатель при сравнении моделей.

## MAPE — средняя абсолютная процентная ошибка
Показывает средний размер ошибки относительно фактического значения в процентах.

## SMAPE — симметричная средняя абсолютная процентная ошибка
Используется как дополнительная относительная метрика качества.

Чем меньше значение каждой из перечисленных метрик, тем точнее прогноз.

# Ограничения исследования

## 1. Небольшой объём выборки

В распоряжении имеется только **84 месячных наблюдения**.
Это особенно существенно для нейронной архитектуры Transformer.

Поэтому выводы о сравнении моделей относятся к текущему набору данных и выбранному тестовому периоду.

## 2. Внешние факторы в тестовом периоде

В ретроспективном тесте 2025 года фактические значения макроэкономических факторов считаются известными.
Таким образом, прогноз моделей с внешними признаками является **условным прогнозом при известных внешних условиях**.

При прогнозировании действительно будущих месяцев фактические значения:
- ключевой ставки;
- валютного курса;
- промышленного производства;
- оборота розничной торговли;
- других макропоказателей
- ещё неизвестны.

Для практического будущего прогноза необходимо использовать внешние прогнозы или заранее подготовленные сценарии этих показателей.

## 3. Высокая ошибка прогноза заявок

Даже лучший из рассмотренных подходов показывает высокую относительную ошибку для applications.
Это может быть связано с:
- высокой нестабильностью ряда;
- структурными изменениями;
- изменениями маркетинговой активности;
- изменениями процессов регистрации заявок;
- недостатком объясняющих факторов.

# Основной вывод

На выбранном тестовом периоде 2025 года XGBoost показал минимальную ошибку среди рассмотренных подходов как для продаж, так и для количества заявок.

При этом:
- для quantity получена существенно более высокая точность, чем у сезонного наивного прогноза;
- для applications ошибка остаётся высокой даже у лучшего из рассмотренных подходов;
- Transformer не продемонстрировал преимущества на выборке из 84 месячных наблюдений;
- результаты моделей с внешними факторами следует интерпретировать как условный ретроспективный прогноз при известных макроэкономических условиях.

Проект демонстрирует полный цикл работы с временным рядом: от подготовки данных и разведочного анализа до сравнения моделей, интерпретации результатов и формирования материалов для дальнейшего практического развития.
