# Итоги моделирования

Результаты относятся к выбранному тестовому периоду 2025 года.
Для моделей с внешними факторами тест интерпретируется как условный прогноз при известных макроэкономических условиях.
Для реального будущего прогноза потребуются прогнозные или сценарные значения внешних факторов.

## quantity
- На выбранном тестовом периоде минимальный RMSE среди проверенных моделей показала **XGBoost**: 612.29.
- Лучший результат среди рассмотренных классических подходов: **XGBoost**, RMSE = 612.29.
- По сравнению с лучшим классическим подходом RMSE Transformer выше на 95.3%.

- Для прогнозирования продаж этот результат можно использовать как основание для дальнейшей апробации модели, регулярно переоценивая качество по мере появления новых месяцев.

## applications
- На выбранном тестовом периоде минимальный RMSE среди проверенных моделей показала **XGBoost**: 9632.98.
- Лучший результат среди рассмотренных классических подходов: **XGBoost**, RMSE = 9632.98.
- По сравнению с лучшим классическим подходом RMSE Transformer выше на 101.1%.

- Для заявок даже у модели с минимальным RMSE относительная ошибка остаётся высокой (MAPE = 89.9%). Поэтому результат следует трактовать как лучший среди рассмотренных подходов, а не как готовое решение для практического использования.

## Ограничение выборки
- В анализе доступно 84 месячных наблюдения. Вывод о сравнении моделей относится к этому набору данных и выбранному тестовому периоду, а не к универсальному превосходству одной архитектуры.
- Transformer сохранён в сравнении намеренно: отсутствие выигрыша на небольшой выборке показывает, что более сложная модель не обязательно обеспечивает более точный прогноз.
